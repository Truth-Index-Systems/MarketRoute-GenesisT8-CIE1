# MarketRoute V2 — Build 15A Light Commercial Identity Pass

## Purpose

Separate MarketRoute's product identity from the darker, engineering-centre identity of Truth Index Systems while preserving the same constitutional intelligence architecture.

## Product direction

- Off-white application canvas for clarity and day-to-day usability.
- Gradient navy used for navigation, verdicts and selective emphasis rather than as the entire interface.
- MarketRoute blue remains the signature action and route accent.
- White, low-shadow working surfaces replace dark nested SaaS cards.
- Commercial language remains primary; Genesis / Truth / R4 / R5 / R6 remain audit and provenance vocabulary.
- Layout density is tightened so whitespace is intentional rather than empty.

## Surfaces updated

- Public front door.
- Product walkthrough / value-first preview.
- Sign in, sign up and onboarding shell.
- Application sidebar and top bar.
- Founder Command Centre.
- Campaign views.
- Company intelligence.
- Opportunity workspace.
- Research views.
- Engagement views.
- Evidence / provenance drawer.
- Core design-system presentation.

## Preview density correction

The final Genesis research panel now spans the preview width and displays its states in a three-column decision strip on desktop. The previous oversized editorial statement has been replaced with a compact navy value band explaining three concrete outcomes: know why, know who, and know what is ready.

## Constitutional scope

This build changes presentation only. It does not change Truth, R4, R5, R6, opportunity authority, engagement execution policy, persistence, database schema or Supabase migrations.
