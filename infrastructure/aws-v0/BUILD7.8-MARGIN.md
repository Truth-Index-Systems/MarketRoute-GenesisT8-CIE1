# AWS V0 Build 7.8 — Semantic Margin Proof

Status: SOURCE CERTIFICATION TARGET
Live actuals: PENDING AWS BEDROCK QUOTA

## Purpose

Build 7.8 formalises the economic view of MarketRoute semantic operations without allowing promotional credits to hide the underlying cost of AI usage.

## Frozen economic doctrine

- Economic cost is based on equivalent model usage cost.
- Cash cost is a separate accounting field.
- AWS credits may reduce cash spend but never reduce economic cost.
- Margin proof fails closed when any operation in the measured set lacks economic cost coverage.
- Partial cash attribution is never presented as complete cash cost.
- Mature semantic COGS target is 20-30% of workload revenue.
- Cost per operation, per 100 operations, and per 1,000 operations are first-class projections.
