# MarketRoute V2

Constitutional rebuild of MarketRoute.

## Current build

**Build 9 — Unified Authority Lifecycle**

The live authority spine is now:

`Seller Genome + Target Truth → R4 Commercial Reality → Relationship Truth/Graph → R5 Route Authority → Contact Truth → R6 Contact Authority → derived authority lifecycle`

Exactly three authority writers exist: R4, R5 and R6. Build 9 adds no fourth writer. It composes the three current authority layers into a categorical lifecycle envelope and a shared `authorityReady` predicate.

Human workflow is deliberately independent. `APPROVED + stale authority` is valid history; it is simply non-executable until R4/R5/R6 are current again. Approval/rejection is never silently rewritten by an authority revalidation cycle.

Execution permission remains future work. Build 9 exposes a derived `isExecutableNow` predicate for later engagement code, but it does not create an `EXECUTION_PERMISSION` authority record and does not send anything.
