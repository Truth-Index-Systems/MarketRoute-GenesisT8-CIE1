# MarketRoute V2

Constitutional rebuild of MarketRoute.

## Current build

**Build 7 — Relationship Truth + Canonical Commercial Graph / R5**

The live reasoning spine is now:

`evidence → Truth → seller genome → R4 Commercial Reality → Truth-qualified relationship graph → R5 structural route authority`

Two authority writers exist: R4 and R5. R5 can prove structural reachability, but a route through a named person or personal channel is explicitly marked `CONTACT_TRUTH_REQUIRED`; Build 8 owns contact identity/employment/role/channel authority.

No legacy compatibility layer exists and no numeric score/confidence/rank may create route authority.
