# MarketRoute V2

**Build 1 — Constitutional Repository Foundation**

MarketRoute V2 is a clean-room implementation. V1 is not a runtime dependency.

## Build 1 commands

```bash
npm install
npm run constitution:check
npm run typecheck
npm run build
```

## Build 1 scope

Included:
- clean Next.js/TypeScript project shell;
- constitutional source layout;
- AI ownership contract;
- authority manifest;
- layer/import enforcement;
- V1 legacy quarantine validator;
- adversarial constitutional fixtures;
- minimal MarketRoute-blue compile shell.

Not included:
- Supabase schema;
- OpenAI integration;
- Truth mathematics;
- commercial-reality logic;
- relationship graph;
- contact truth;
- opportunity logic;
- engagement logic.

Those belong to later builds and may not leak into Build 1.
