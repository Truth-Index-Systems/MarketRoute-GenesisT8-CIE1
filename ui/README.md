# UI — MarketRoute V2

Presentation layer only. The UI may consume canonical application read models, but it must never calculate commercial authority, Truth state, workflow state, research priority, engagement permission, or database currentness.

## Build 14 design system

MarketRoute uses a near-black intelligence workspace with a blue primary system:

- Primary blue: `#2F8CFF`
- Soft blue: `#76B6FF`
- Deep blue: `#0C65CF`
- Background: `#05080D`

The design language is precise, sparse and evidence-led. Status colour is presentation only: the semantic category must already be supplied by the application contract.

The product surface is namespaced under `/app`. `/` is reserved for the public acquisition experience that will be completed in Build 16.

Build 14 contains explicit non-authoritative preview data to exercise the component system. Build 15 replaces that preview with canonical Build-13 application reads.
