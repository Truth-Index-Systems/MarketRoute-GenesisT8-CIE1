# Engagement application — Build 12

The application orchestrates an system-ready/current opportunity into a deterministic channel strategy, provider-generated language, categorical AI self-review, campaign policy and human message approval, queueing and send-time delivery. All queue/send permissions are re-proven by database RPCs from the live authority envelope.

`EngagementLanguageProvider` and `EngagementDeliveryProvider` are vendor-neutral and intentionally unconfigured by default. A delivery provider must honor the supplied queue-item idempotency key. Unknown delivery state fails to reconciliation rather than automatic resend.
