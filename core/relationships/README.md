# Relationship Truth + Canonical Commercial Graph

Build 7 makes relationship assertions first-class evidence subjects. A canonical relationship is only traversable when its `relationship.exists` claim is Truth-qualified as `KNOWN` or `SUPPORTED` at the R5 reference time.

R5 proves structural reachability. It does **not** prove that a named person still works at the target or owns a personal channel; paths containing a PERSON or personal access point are emitted as `CONTACT_TRUTH_REQUIRED` for Build 8.

No numeric confidence, score, weight, or ranking can create an edge or route.
