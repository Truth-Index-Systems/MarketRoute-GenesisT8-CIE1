# Engagement Engine — Build 12

The engagement core is non-authoritative. It maps an already-authorised R6 path to a channel strategy, canonicalises outbound language, accepts AI language quality only as a categorical `PASS / REWRITE / BLOCK` judgement, and exposes deterministic queue eligibility. Numeric review diagnostics are telemetry only.

Generation receives structured seller/objective/offering context and current R4-satisfied target facts, plus the exact R6-authorised route. It does not consume raw evidence excerpts.

Commercial/execution permission remains database-derived from current R4/R5/R6 plus human workflow at queue and send time.
